# Generated Output Write Hardening

Status: implemented and independently audited on the uncommitted working tree, 2026-10-07. This task does not change Myers32 algorithms, generated bytes, published bundles, benchmark claims, or release state.

## Problem and decision

`codegen/tools/generated-output.cjs` currently truncates each owned file in place. Myers32 A owns both a comparison artifact and the production `/v2` source, so a failed second write can leave them out of sync. Stage complete files beside every destination before replacing either output. Keep `--check` read-only and retain its normalized-line-ending comparison.

## Acceptance

- Reject output aliases and symlink escapes before mutation. Preserve existing file bytes on staging failure and roll back handled publication failures; remove only owned temporary files. If rollback itself fails, retain and report any available recovery copy.
- Replace each destination with a same-directory rename. For Myers32 A, stage both outputs first, then publish with rollback for handled failures. An abrupt process kill between two renames cannot be made a cross-directory atomic transaction; `codegen:check` must detect the resulting drift.
- Test partial staging writes, failed second publication, rollback failure, symlink/alias rejection, check-mode immutability, and successful A/B refreshes without changing generated bytes.
- Run focused tests, `codegen:check`, and the local release gate. Verify production bundle and package fingerprints. Do not stage, commit, push, publish, dispatch cloud CI, or time benchmarks.

## Evidence and limits

Exclusive creation marks a temporary or backup file as owned only after creation succeeds, so an `EEXIST` collision cannot delete another file. Both real generator refreshes and `codegen:check` passed. Myers32 A and B output SHA-256 values matched their pre-task bytes.

The generator assumes one writer. An abrupt process kill between A's two renames can leave complete but mismatched outputs; `codegen:check` detects that drift and a rerun repairs it. Handled rollback restores bytes, not necessarily the original mode, ACL, or modification time. Concurrent edits or path replacements are outside this local-generator contract.
